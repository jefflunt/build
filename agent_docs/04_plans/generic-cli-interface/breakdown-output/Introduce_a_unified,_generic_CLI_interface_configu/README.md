# Introduce a unified, generic CLI interface configured via `~/.build/config.yml`. Decouple the orchestrator logic from the specific LLM executable by creating an `internal/cli` package with a standard `Client` interface and an `opencode` driver. Refactor the `build` command and router to use this generic interface based on the user's parsed `agent_adapter` configuration.

This task involves refactoring the application to decouple its orchestration logic from the hardcoded `opencode` CLI dependency. We will introduce a new configuration mechanism utilizing `~/.build/config.yml` to specify the active agent adapter, including CLI name, provider, and model (e.g., `agent_adapter: opencode:google/gemini-3.5-flash`). A new `internal/cli` package will define a standard `Client` interface to handle running CLI sessions and querying models. Initially, an `opencode` driver will be implemented to conform to this interface. Finally, the main entry point and the router will be refactored to consume the parsed configuration, inject the appropriate CLI client, and execute commands through the interface abstraction.
