# Implement LLM environment variable validation, dynamic model suggestions via 'opencode' execution (with static fallback), and integrate the check into runRouter() within cmd/build/main.go to exit with code 1 on failure.

This task requires adding functionality to check for the presence of the `BUILD_LLM_PROVIDER` and `BUILD_LLM_MODEL` environment variables. If either variable is missing, the program must halt its normal operation. To assist the user, the program should attempt to execute `opencode models` using `os/exec` to fetch a list of valid models. If the `opencode` command is unavailable or fails, it should use a static fallback list of common models. Finally, a detailed setup guide must be printed to standard error or standard output, followed by exiting the program with a status code of 1. This validation step needs to be integrated into `runRouter()` inside `cmd/build/main.go` so it runs proactively before core command logic executes.
