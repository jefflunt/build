# Project Orientation: Minimalist AI Orchestrator

## Goal
Build a lightweight, autonomous AI agent orchestrator.

## Core Philosophy
- **Minimalist Parts:** Keep the architecture simple and focused.
- **Autonomous Roles:** Agents perform specific, distinct functions.
- **Observability via Logging:** Agents log their activities as an application (not through interactive CLI monitoring).

## Architecture Context
- Orchestrator manages agent life cycle and messaging.
- Agents operate autonomously based on assigned roles.
- Logging mechanism is central to observability.
