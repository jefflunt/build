# Implement a 'build rm' subcommand that allows users to delete tasks and all their descendants by ID or status. The command must recursively calculate the affected tasks, prompt the user for confirmation, and safely purge the records from the tasks, comments, and audit_logs tables.

The task involves adding a new `build rm` command to recursively delete tasks and their descendants by either ID or status. This includes fetching the tree of tasks from the database, presenting a confirmation prompt to the user with the total count, and performing a clean cascade deletion across `tasks`, `comments`, and `audit_logs` tables. Because this spans multiple distinct layers of the application (database queries, interactive CLI logic, and main application routing), it needs to be decomposed.
