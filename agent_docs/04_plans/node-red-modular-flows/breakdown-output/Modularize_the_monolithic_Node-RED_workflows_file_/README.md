# Modularize the monolithic Node-RED workflows file into versioned files and native subflows located inside sibling directories flows/ and subflows/, and update the synchronization CLI commands to handle bidirectional merging, partitioning, additions, deletions, and renames cleanly via a local state tracking database file (.build/sync_state.json).

This task aims to modularize the single, monolithic workflows/sdlc-orchestrator.json file into versioned, modular flows and subflows inside twin directories flows/ and subflows/. In addition, the sync engine will be upgraded to act as a bridge between the local multi-file modular directory structure and Node-RED's flat JSON array API. To prevent loops and reliably track additions, deletions, and renames, a state tracking mechanism (.build/sync_state.json) is introduced to monitor changes bidirectionally between the local workspace and the remote Node-RED deployment.
