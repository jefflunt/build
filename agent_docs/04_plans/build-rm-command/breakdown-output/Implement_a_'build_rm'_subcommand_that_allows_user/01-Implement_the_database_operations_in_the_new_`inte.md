# Implement the database operations in the new `internal/rmcmd` package to recursively resolve descendant task IDs based on a target ID or status, and execute a transaction to safely delete those tasks and their associated records from the `tasks`, `comments`, and `audit_logs` tables.

This task requires implementing the database interaction logic within the new `internal/rmcmd` package. You will need to write functions that can query the SQLite database to recursively resolve and collect all descendant task IDs when provided with a target task ID or status. After identifying the complete set of affected IDs, the logic must execute a series of deletion statements to safely purge the records from the `audit_logs`, `comments`, and `tasks` tables, typically ordered to avoid foreign key constraint violations if they exist. The operations should ideally be wrapped in a transaction to guarantee data consistency and rollback on errors.
